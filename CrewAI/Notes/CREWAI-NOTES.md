## 📊 QUICK REFERENCE

### CrewAI in One Picture:
```
You: "Do this project"
           ↓
         Crew
    ├─ Agent 1: Parser
    ├─ Agent 2: Analyzer
    └─ Agent 3: Writer
           ↓
      Tasks Run in Order:
    Task 1 → Task 2 → Task 3
           ↓
       Results Returned
           ↓
         Output
```

### 3 Core Components:
```
AGENT = Worker (has role, goal, backstory)
TASK = Job (what to do, expected output)
CREW = Manager (coordinates agents & tasks)
```

### How Agents Think:
```
Task Description
    ↓
Agent receives it
    ↓
LLM analyzes (AI thinking)
    ↓
Agent acts on LLM guidance
    ↓
Returns result
```

### Cost Estimate:
```
1 resume screening = $0.10-0.20
50 resumes = $5-10
100 resumes = $10-20

vs Manual:
50 resumes = 2.5 hours × $40/hr = $100
```
