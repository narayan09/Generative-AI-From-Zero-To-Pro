# 🧠 Introduction to Generative AI

Generative AI (GenAI) is a branch of Artificial Intelligence that focuses on **creating new content** — like text, images, music, videos, or code — rather than just analyzing existing data.

---

## 🤖 What is Generative AI?

In simple terms, Generative AI is **AI that creates**.

It can:
- Write stories, blogs, or code  
- Draw pictures or design art  
- Compose music  
- Generate human-like voices  
- Create entire videos  

It uses machine learning models like:
- **LLMs (Large Language Models)** → ChatGPT, Gemini  
- **Diffusion Models** → Stable Diffusion, Midjourney  
- **GANs** → Used for realistic image & video creation  
- **VAEs** → Used in sound and image generation  

---

## 📜 History and Evolution

| Era | Development | What Happened |
|------|--------------|----------------|
| **1950s–1980s** | Early AI | Focused on rule-based systems |
| **1990s–2010s** | Machine Learning | AI started learning from data |
| **2014** | GANs introduced | AI could now generate realistic images |
| **2018–2020** | Transformers & GPT | AI could now understand and write text |
| **2021–2024** | GenAI explosion | Tools like ChatGPT, DALL·E, Midjourney emerged |
| **Today** | Multimodal AI | AI now handles text, image, voice & video |

## 🌍 Key Applications of Generative AI

### 📝 Text Generation
AI that writes like humans.  
Examples:
- ChatGPT, Claude, Gemini  
- GitHub Copilot (code writing)

👉 *Use case:* Write blogs, summarize text, generate code.

---

### 🎨 Image Generation
AI that creates visuals from text.  
Examples:
- DALL·E, Midjourney, Stable Diffusion  

👉 *Use case:* Create artwork, posters, logos.

---

### 🔊 Audio & Voice Generation
AI that creates music or human-like speech.  
Examples:
- Bark, ElevenLabs, Tortoise-TTS  

👉 *Use case:* Create podcasts, audiobooks, or songs.

---

### 🎬 Video Generation
AI that creates videos using text prompts.  
Examples:
- Runway, Pika Labs, Synthesia  

👉 *Use case:* Generate explainer videos or ads automatically.
