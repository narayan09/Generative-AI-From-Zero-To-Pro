Database (SQL) Mode

For queries that retrieve, count, aggregate, or filter Jira tickets.

#	Question	What it tests
1	How many open bugs are there?	Simple JOIN + COUNT, filter by status and type
2	Show me all issues assigned to "John Doe" that are still open.	Name lookup, join users, filter status
3	List the top 5 projects with the most issues.	GROUP BY, COUNT, ORDER BY, LIMIT
4	What is the average resolution time (in days) for closed issues?	DATEDIFF, AVG, status filter
5	Which user has reported the most bugs?	GROUP BY reporter, COUNT, filter type='Bug'
6	List all issues created last week.	Date calculation (CURRENT_DATE – 7)
7	How many issues are currently overdue? (due_date < now, not closed)	Date comparison, NULL handling
8	What are the titles of all "Critical" priority tickets?	JOIN priorities, filter by priority_name
9	Show me all comments written by "Alice Smith" on unresolved issues.	Multi‑table JOIN (comments → issues → users)
10	Which project has the highest percentage of "Blocker" tickets?	Subquery or window function – more challenging
Tip: The LLM may occasionally need a retry; if a query returns an error, try rephrasing (e.g., use “summary” instead of “title”).
